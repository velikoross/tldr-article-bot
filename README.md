# TLDR Article Bot

Telegram-бот, который читает статью по ссылке, делает выжимку и честно говорит, стоит ли тратить на неё время. Вердикт учитывает ваши интересы.

Работает с обычными сайтами, блогами, Habr, vc.ru, Medium, новостными и англоязычными сайтами, а также с PDF (если в PDF есть текстовый слой). Ответ всегда на вашем языке (по умолчанию на русском), на каком бы языке ни была статья.

## Пример ответа

> 📰 **[Как мы ускорили CI в четыре раза](https://devnotes.example/ci-speedup)**
> 🌐 devnotes.example · ✍️ Иван Петров · 📅 12.03.2026 · ⏱ ~11 мин
>
> ✅ **Читать** — Практический разбор с цифрами и готовыми конфигами — прямо про ваш DevOps.
>
> 🎯 **Кому и зачем**
> *Практика* · DevOps- и бэкенд-разработчикам: приёмы кэширования зависимостей и шардирования тестов, которые можно повторить за день.
>
> 📝 **Выжимка**
> • Сборка монорепозитория занимала 40 минут, почти половина уходила на установку зависимостей.
> • Кэш по хэшу lock-файла сэкономил ~15 минут на каждом запуске.
> • Docker-слои пересобирались из-за неудачного порядка COPY: после перестановки сборка образа ускорилась с 12 до 4 минут.
> • Тесты разбили на 4 шарда по истории длительности: 10 минут → 3.
> • Итог: 40 минут → 10, очередь в CI исчезла без нового железа.
> • Главный вывод автора: сначала измерьте, куда уходит время, и только потом оптимизируйте.
>
> `[🌐 Перевести]` `[📄 Полный перевод]`
> `[🔁 Подробнее]`

Если статья рекламная, кликбейтная, устаревшая или пересказывает чужой материал, бот так и скажет:

> 📰 **[Секретная стратегия, которая сделала меня миллионером](https://money-blog.example/secret)**
> 🌐 money-blog.example · ⏱ ~5 мин
>
> ⏭ **Можно пропустить** — По сути реклама платного курса; конкретики почти нет, а крипта вам не интересна.
>
> 🎯 **Кому и зачем**
> *Реклама продукта* · Новичкам, которые выбирают курс по трейдингу.
>
> ⚠️ **Обратите внимание**
> • **Реклама**: Половина текста — описание курса со ссылкой на оплату.
> • **Кликбейт**: Заголовок обещает «секретную стратегию», в тексте её нет.
>
> 📝 **Выжимка**
> • Автор рассказывает, как заработал на токенах в 2021 году.
> • Советует «покупать на просадках» без критериев входа.
> • Остальное — программа курса и отзывы учеников.

Если скачать статью не получилось, бот объясняет причину простыми словами:

> ⛔ news.example: сайт не пустил бота (403). Часто это защита от ботов или доступ только из определённых стран. Пришлите текст статьи сообщением.

> 🔒 times.example: статья за платным доступом, бот видит только начало. Если у вас есть доступ — пришлите текст статьи сообщением.

### Кнопки под ответом

- **🌐 Перевести** — та же выжимка на вашем втором языке (задаётся в `/settings`).
- **📄 Полный перевод** — перевод всей статьи файлом `.md` или страницей telegra.ph (формат задаётся в `/settings`). Иностранную статью бот переводит на основной язык, русскую — на второй.
- **🔁 Подробнее** — длинная выжимка с разбором по разделам статьи.

### Что ещё умеет

- Несколько ссылок в одном сообщении — разбирает каждую отдельно (до `MAX_LINKS_PER_MESSAGE`).
- Пересланный пост из канала: ищет ссылки в тексте, подписи, скрытых ссылках и кнопках поста. Служебные ссылки `t.me` пропускает.
- Длинный текст без ссылки — выжимка этого текста.
- Пока статья обрабатывается, бот показывает «⏳ Читаю статью…» и статус «печатает». Потом это сообщение заменяется ответом.

## Команды

| Команда | Что делает |
|---|---|
| `/profile` | Описание того, чем вы занимаетесь и что вам интересно. Например: `/profile бэкенд на Python, DevOps, велоспорт; не интересны крипта и маркетинг`. Без текста бот покажет текущий профиль и попросит прислать новый. `/profile clear` — удалить профиль. Без профиля статья оценивается в целом. |
| `/settings` | Язык выжимки, второй язык для перевода, формат полного перевода (.md или telegra.ph). |
| `/history` | Последние 20 ссылок с вердиктами. |
| `/help` | Справка. |
| `/llmtest` | *Админ.* Тестовый запрос к нейросети: провайдер, модель, время ответа, `finish_reason`, токены или текст ошибки провайдера. Заодно сбрасывает память об отклонённых запросах (см. ниже). |
| `/instructions` | *Админ.* Ваши указания, которые добавляются ко всем промптам. `/instructions никогда не добавляй дисклеймеры` — задать, `/instructions off` — отключить, `/instructions reset` — вернуть значение из `LLM_INSTRUCTIONS`. |
| `/stats` | *Админ.* Сколько статей и ответов лежит в кэше. |

## Пользователи и доступ

- `ADMIN_IDS` — все команды, без дневного лимита.
- `ALLOWED_IDS` — друзья.
- Всем остальным бот отвечает «🔒 Это приватный бот» и показывает их Telegram ID. Так проще всего узнать собственный ID при первом запуске: напишите боту, скопируйте номер в `ADMIN_IDS` и перезапустите контейнер.
- У каждого пользователя свои профиль, языки и история.
- `DAILY_LIMIT_PER_USER` — сколько **новых** статей в день может обработать друг (0 — без лимита). Повторная ссылка на сегодняшнюю статью лимит не тратит. Сутки считаются по UTC.

## Запуск

### Docker Compose (рекомендуется)

```bash
mkdir tldr-article-bot && cd tldr-article-bot
curl -O https://raw.githubusercontent.com/velikoross/tldr-article-bot/main/docker-compose.yml
curl -o .env https://raw.githubusercontent.com/velikoross/tldr-article-bot/main/.env.example
nano .env          # BOT_TOKEN, ADMIN_IDS, LLM_API_KEY, LLM_MODEL
docker compose up -d
docker compose logs -f
```

База SQLite (кэш, профили, история) лежит в `./data/bot.db`. Веб-порт не нужен: бот работает через long polling.

Автообновление через cron:

```cron
0 4 * * * cd /opt/tldr-article-bot && docker compose pull -q && docker compose up -d
```

### Без Docker

```bash
python3.12 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # заполните; DB_PATH=./data/bot.db
python -m bot
```

### Собрать образ локально

```bash
docker build -t velikoross/tldr-article-bot:latest .
```

## Настройки

Все параметры с комментариями — в [`.env.example`](.env.example). Главные:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен от @BotFather |
| `ADMIN_IDS`, `ALLOWED_IDS` | — | Telegram ID через запятую |
| `DAILY_LIMIT_PER_USER` | `0` | Лимит новых статей в день для друзей |
| `LLM_PROVIDER` | `openrouter` | `openrouter`, `openai` (и любой OpenAI-совместимый API), `anthropic` |
| `LLM_API_KEY` | — | Ключ провайдера (для Ollama не нужен) |
| `LLM_MODEL` | `google/gemini-2.5-flash` | Модель |
| `LLM_BASE_URL` | стандартный | Например `https://api.deepseek.com/v1` или `http://192.168.1.10:11434/v1` (Ollama) |
| `LLM_MAX_TOKENS` | `8000` | Минимальный лимит ответа. Меньше бот не запрашивает никогда |
| `LLM_REASONING` | пусто | `off` / `low` / `medium` / `high`. Пусто — не передавать |
| `LLM_CONTEXT_TOKENS` | `32000` | Контекст модели. Длинные статьи режутся на части по этой границе |
| `LLM_INSTRUCTIONS` | — | Указания ко всем промптам (можно менять командой `/instructions`) |
| `LLM_EXTRA_BODY` | — | JSON с дополнительными полями запроса, например настройки `provider` в OpenRouter |
| `DEFAULT_LANGUAGE` | `ru` | Язык выжимки по умолчанию |
| `DEFAULT_TRANSLATION_LANGUAGE` | `en` | Второй язык по умолчанию |
| `FULL_TRANSLATION_FORMAT` | `md` | `md` или `telegraph` |
| `FETCH_MAX_BYTES` | `5242880` | Не скачивать страницы и PDF больше 5 МБ |
| `CACHE_TTL_DAYS` | `30` | Срок жизни кэша (0 — бессрочно) |

### Примеры подключения нейросети

```env

# OpenAI

# DeepSeek

# Anthropic

LLM_API_KEY=sk-ant-...
LLM_MODEL=claude-sonnet-5-5
```

### Как бот обходит типичные проблемы с моделями

- **Рассуждающие модели.** Лимит ответа никогда не меньше `LLM_MAX_TOKENS`. Глубину рассуждений задаёт `LLM_REASONING`: у OpenRouter это `reasoning` (`off` → `{"enabled": false}`, иначе `{"effort": ...}`), у OpenAI — `reasoning_effort`, у Anthropic — `thinking.budget_tokens`. Если ответ пустой или обрезан (`finish_reason=length` / `stop_reason=max_tokens`), пользователь получает понятное сообщение с подсказкой, что поменять. В чат не попадает обрезанный мусор.
- **Ответ не в JSON.** Бот вытаскивает JSON из ```-блоков, `<think>…</think>` и пояснений вокруг. Если JSON так и нет — один повтор с напоминанием, потом понятная ошибка.
- **Ошибки 400–404 от провайдера** (запрещённые в аккаунте провайдеры, политика данных OpenRouter, неверная модель или ключ). Бот показывает текст провайдера как есть, вместе с `metadata.raw`, и не повторяет запрос. Каждая такая ошибка пишется в лог один раз. Если запрос уже был отклонён, при следующей такой же попытке ответ берётся из памяти без обращения к провайдеру. Исправили настройки — выполните `/llmtest`: он проверит подключение и сбросит эту память (или просто перезапустите бота).
- **429, 5xx, таймауты** повторяются дважды с паузой.

## Как это устроено

1. **Ссылки.** Ищутся в тексте, подписях и entities сообщения (включая скрытые ссылки и ссылки без `https://`), в кнопках и предпросмотре пересланного поста.
2. **Кэш по нормализованному URL.** Схема, `www.`, `m.`, якорь, `utm_*`, `fbclid`, `gclid`, `yclid` и прочие метки отбрасываются, остальные параметры сортируются. Повторная ссылка не скачивается и не отправляется в нейросеть.
3. **Скачивание** (httpx): браузерный User-Agent, лимит 5 МБ (по заголовку и по факту), таймаут, редиректы. Для 401/402/403/404/429/5xx, таймаута, слишком большого файла и неподходящего типа (картинка, видео) — отдельные понятные сообщения.
4. **Извлечение текста.**
   - Для Habr, vc.ru, dtf.ru и Medium есть правила разметки: из блока статьи убираются опросы, подвал и комментарии.
   - Затем trafilatura (сохраняет заголовки, списки и код в Markdown).
   - Если текста слишком мало — readability-lxml, потом `articleBody` из JSON-LD.
   - Метаданные (заголовок, автор, дата) берутся из разметки сайта, JSON-LD, `og:` и `meta`.
   - Платный доступ определяется по `isAccessibleForFree`, классам `paywall` и типичным фразам. Если текста нет — сообщение о платном доступе. Если видна только часть — выжимка с пометкой «неполный текст».
   - PDF читается через pypdf. Для сканов без текстового слоя — отдельное сообщение.
5. **Длинные статьи.** Если текст не влезает в `LLM_CONTEXT_TOKENS`, он режется по абзацам. По каждой части делаются заметки (параллельно, `LLM_CONCURRENCY`), из заметок — итоговая выжимка. Заметки сохраняются: для другого профиля или для «Подробнее» их не нужно делать заново.
6. **Кэш ответов.**
   - Выжимка кэшируется по ключу «статья + язык + профиль + указания»: вердикт зависит от профиля, поэтому друг с другими интересами получит свой вердикт. Статья при этом заново не скачивается.
   - Переводы кэшируются по ключу «статья + язык».
7. **Оформление.** HTML, всё экранируется, предпросмотр ссылок выключен. Длина считается как в Telegram: видимый текст без тегов, в единицах UTF-16. Основной ответ всегда помещается в одно сообщение (≤ 4096): при необходимости бот укорачивает пункты. Подробный разбор может занять несколько сообщений.

## Разработка

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты не ходят в сеть: нейросеть и сайты заменены заглушками (`httpx.MockTransport`, фейковый клиент LLM). HTML-фикстуры лежат в `tests/fixtures/`.

## CI и Docker Hub

`.github/workflows/ci.yml`: тесты → сборка образа `linux/amd64` + `linux/arm64` → публикация в Docker Hub как `velikoross/tldr-article-bot` (`latest` для `main`, тег коммита, версии для тегов `v*`).

- Логин: переменная репозитория `DOCKERHUB_USERNAME` (Settings → Secrets and variables → Actions → Variables), по умолчанию `velikoross`.
- Токен: секрет `DOCKERHUB_TOKEN`. Без него образ собирается, но не публикуется.

## Структура

```
bot/
  __main__.py      запуск, aiogram Dispatcher
  config.py        настройки из .env
  access.py        доступ: админ / друг / чужой
  handlers.py      команды, сообщения, кнопки
  service.py       путь от ссылки до ответа: кэш, лимиты, переводы
  urls.py          поиск и нормализация ссылок
  fetcher.py       скачивание с лимитами и понятными ошибками
  extractor.py     извлечение текста (trafilatura, readability, правила сайтов, PDF)
  summarizer.py    промпты, разбор JSON, длинные статьи по частям
  formatting.py    HTML и длина сообщения по правилам Telegram
  telegraph.py     публикация полного перевода на telegra.ph
  llm/             OpenRouter / OpenAI-совместимые / Anthropic
tests/             pytest + фикстуры
```
